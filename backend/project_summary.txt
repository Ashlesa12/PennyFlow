PennyFlow Backend Summary
=========================

Project purpose:
A personal expense tracking backend built with FastAPI, SQLAlchemy, and JWT authentication.

What is implemented:
- User signup and login
- Password hashing with bcrypt
- JWT-based authentication
- Protected routes for authenticated users
- Expense creation
- Expense retrieval for the logged-in user
- Database models for users, categories, and expenses

Main files:
- app/main.py: app entry point and router registration
- app/database.py: database engine and session setup
- app/models.py: SQLAlchemy models
- app/schemas.py: request/response validation schemas
- app/security.py: JWT authentication helpers
- app/routes/auth.py: signup/login/auth routes
- app/routes/expenses.py: expense endpoints
- app/services/auth_service.py: user creation logic
- app/utils.py: password hashing and verification

Next possible steps:
- Update/delete expenses
- Category management
- Expense summaries and analytics
- Tests and deployment
